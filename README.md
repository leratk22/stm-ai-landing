# STM AI Landing

Лендинг студии STM — «Сайт для вашего бизнеса за 390 000 ₽».
Вёрстка по макету Figma, одиннадцать секций, адаптив от 375px.

## Стек

- **Astro 7** — статическая сборка, ноль JS по умолчанию
- **Tailwind 4** — токены дизайна в `@theme`
- **TypeScript** (strict)
- **Node 22** (см. `.nvmrc`)

## Запуск

```sh
pnpm install
pnpm dev
```

Сборка — `pnpm build`, результат в `dist/`.

## Структура

```
src/
  components/
    sections/   — секции страницы, по одной на блок макета
    ui/         — переиспользуемое: кнопка, тег, карточка, сетка линий
  data/content.ts — весь копирайт, отдельно от разметки
  scripts/      — градиентный шейдер, появление при скролле, поп-ап формы
  styles/       — токены и типографическая шкала
```

Тексты вынесены в `src/data/content.ts` — править копирайт можно,
не трогая компоненты.

## Форма обратной связи

Поп-ап «Обсудить проект» отправляет заявку на адрес из переменной
`PUBLIC_FORM_ENDPOINT` (см. `.env.example`). Подойдёт любой обработчик,
принимающий POST с FormData.

Пока переменная не задана, форма не отправляется и сообщает об этом —
ложного успеха не показывает.

## Особенности реализации

- **Градиент героя** — фрагментный шейдер на WebGL2 без библиотек.
  Рисует только пока секция в зоне видимости; при `prefers-reduced-motion`
  не поднимается вовсе, остаётся статичная CSS-подложка.
- **Появление блоков** — CSS-переходы на одном IntersectionObserver.
  Структурные линии из-под анимации выведены: каркас секции виден всегда.
- **Таблица сравнения** — на десктопе обычная `<table>`, ниже 1024px
  перестраивается в карточки по параметрам, без горизонтального скролла.
- **FAQ** — нативный `<dialog>`-подобный `<details>`, работает без JS.
- **Шрифт** — Inter, вариативный, самохостинг. Два набора символов, 68 КБ.
